# Патчи compact.sqlite3

Сервер применяет SQL-файлы из `startup/` при запуске, до загрузки игровых данных. Скрипты в этом каталоге входят в сборку и публикацию игрового сервера. Остальные файлы каталога предназначены для ручного импорта.

Давайте новым патчам уникальные имена вида `YYYY-MM-DD-описание.sql`. Сервер выполняет файлы в порядке имён. Каждый файл и его запись в `sql_patches_applied` сохраняются одной транзакцией, поэтому в скрипте следует опускать `BEGIN`, `COMMIT` и `ROLLBACK`. Изменение выпущенного патча оформляйте новым файлом.

Журнал хранится в `Data/compact.sqlite3` рядом с исполняемым файлом. После замены базы сервер при следующем запуске выполняет патчи, которых нет в её журнале. Для применения патчей серверу нужен доступ на запись к базе и каталогу `Data`. При ошибке запуска журнал сервера указывает файл, который нужно исправить перед повторным запуском.

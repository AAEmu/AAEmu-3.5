# EffectTaskManager

## Описание

`EffectTaskManager` планирует задачи эффектов (например, dispel) через
`ITaskManager`.

## Источники данных

Нет внешних источников данных.

`compact.sqlite3` / `compact.server.table.sqlite3` не используются.

## Контейнеры

Нет постоянных контейнеров.

## Обрабатываемые пакеты

`EffectTaskManager` не обрабатывает пакеты.

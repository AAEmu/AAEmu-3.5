# Сверка опкодов AAC 3.5.3.0

Источник проверки — `D:\AA-dump\3503AAC\x2game_dump.dll.i64`. Сверены 439 серверных констант CS и 784 константы SC с 379 и 730 дескрипторами клиента соответственно. Для CS проверялись значения, которые клиент записывает перед отправкой. Для SC проверялись фабрики, слоты регистрации и обработчики. Числа в именах IDA использовались как подсказки при поиске.

Исправлены 39 констант CS и 49 констант SC. Для входящих пакетов одна пара «уровень, opcode» соответствует одному зарегистрированному обработчику. В частности, коды `0x15D`, `0x0F5` и `0x0ED` восстанавливают отдельные обработчики выхода из группы, исключения участника и роспуска группы.

| Opcode SC | Обработчик клиента | Данные |
| --- | --- | --- |
| `0x268` | `OnDoodadQuestAccept` (`0x393FCEE0`) | ID объекта `bc`, ID квеста `uint32` |
| `0x11C` | `OnDoodadCompleteQuest` (`0x393FE8A0`) | ID объекта `bc`, ID квеста `uint32` |
| `0x172` | `OnDoodadSound` (`0x393FEF00`) | ID объекта `bc`, ID звука `uint32` |
| `0x073` | `OnDoodadPhaseMsg` (`0x393FEF80`) | ID объекта `bc`, значение сообщения `uint32` |
| `0x175` | `OnBuffRemoved` | ID объекта `bc`, индекс баффа `uint32` |
| `0x19B` | `OnBuffLearned` (`0x393FC830`) | ID объекта `bc`, ID баффа `uint32` |
| `0x15D` | `OnResultRestrictCheck` (`0x39404F80`) | ID персонажа `uint32`, код `byte`, результат `byte` |
| `0x281` | Сообщение с десериализатором `0x3991D430` | Строка |
| `0x24F` | `OnGamePointChanged` (`0x394009A0`) | Количество записей `byte`, затем вид `byte` и сумма `int32` |

Signpost (`5047`) отдаёт клиенту `0x268` с ID объекта и квестом `250`. Клиент из этого обработчика открывает интерфейс квеста. Принятие через интерфейс использует существующий `CSStartQuestContext` (`0x105`).

## Пакеты, для которых требуется дополнительная проверка

В таблицах остались 30 констант CS и 12 констант SC со значением `0xFFF`. `GameNetwork` пропускает это значение при регистрации. Среди оставшихся заглушек есть унаследованные классы, для которых нужно подтвердить соответствие полей или назначение пакета.

| Класс сервера | Наблюдение в клиенте |
| --- | --- |
| `CSQuestStartWithPacket` | `CSQuestStartWithParam` (`0x060`) содержит вариант параметров после трёх `uint32`. Текущий обработчик читает три поля и пишет их в журнал. |
| `CSRequestSecondPasswordKeyTablesPacket` | `CSRequestSecondPassKeyTables` (`0x118`) содержит поле `pktm`. Текущий обработчик рассчитан на пустое тело. |
| `CSSetupSecondPassword` | `CSCreateSecondPass` (`0x120`) содержит время, индекс таблицы и строку. Текущий обработчик рассчитан на пустое тело уровня 1. |
| `SCShowCommonFarmPacket` | `SCShowCommonFarmShape` (`0x241`) содержит массив позиций. Текущий класс записывает одну позицию при любом значении `count`. |
| `SCMyHouseRemovedPacket` | `SCHouseRemoved` (`0x160`) принимает `tl` и вызывает `OnHouseRemoved`. Для уведомления прежнего владельца при продаже требуется подтвердить, что клиент сохранит дом в мире. |
